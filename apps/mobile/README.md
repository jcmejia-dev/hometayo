# HomeTayo Native Android

React Native + Expo SDK 57. Native sign-in/sign-up, email code verification, secure sessions, property-owner submissions and map pins, map-based all-location rental discovery, and compatible EAS Update downloads.

See [release setup](../../docs/NATIVE_AUTH_MAPS_UPDATES.md) for backend migration, email/Google/Maps configuration, linking the existing EAS project, one initial signed APK build, and later Update app releases.

Development: npm ci, npm run check, npx expo start. Google sign-in, Maps and updates require a configured native build; Expo Go does not validate the final signed app.
